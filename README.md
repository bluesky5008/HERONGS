# HERONGS

키움증권 영웅문 REST API 기반의 국내주식(KOSPI/KOSDAQ) 조회·추천·매매 보조 앱.

시장 전체를 스캔해 투자 기간 관점별로 종목을 추천하고, 개별 종목에 대한 매수/매도/홀딩 의견을 근거와 함께 제시하며, 사용자가 확인한 주문만 실행하는 개인용 투자 도구입니다.

## 핵심 컨셉

- **3개 전략 프로파일, 단일 시스템**: 물리적으로 앱을 나누지 않고 공통 데이터 수집·분석 엔진 위에 세 가지 전략 프로파일을 얹습니다.
  - **장기투자** — 가치·퀄리티 지표(PER/PBR/ROE, 재무 조건)와 장기 추세
  - **중단기 스윙** — 외국인·기관 수급, 이동평균 배열, 상대강도
  - **단타** — 실시간 거래량 급증, 체결강도, 호가 잔량 (WebSocket 실시간 시세)
- **깔때기(funnel) 스캔 구조**: 전 종목 무차별 조회 대신 랭킹 API·조건검색식으로 후보군을 압축한 뒤 후보만 상세 분석합니다. (API 호출량 제한 대응)
- **조건검색식 연동**: 영웅문 HTS에서 작성한 조건검색식을 스캔의 1차 필터로 사용합니다. 전략별 권장 조건식 정의를 문서로 제공합니다.
- **추천 + 확인 후 주문**: 완전 자동매매는 하지 않습니다. 모든 주문은 수량·가격·계좌 대비 비중·제안 손절가를 보여주는 확인 단계를 거쳐 사용자가 승인해야 실행됩니다.
- **성과 추적 피드백 루프**: 모든 추천을 저장하고 사후 수익률을 추적해 전략별 적중률을 검증하고 스코어링 가중치를 데이터로 튜닝합니다.

## 사용 형태 (계획)

- 홈서버(상시 구동 PC)에서 백엔드 실행, 반응형 모바일 웹(PWA)으로 접근
- 외부에서는 Tailscale VPN 경유 접속 (인터넷 직접 노출 금지)
- 텔레그램 푸시 알림: 추천 신호, 손절선 도달, 장전/장후 데일리 브리핑
- 모의투자 도메인(mockapi.kiwoom.com)에서 검증 후 실계좌 전환

## 보안 원칙

- appkey/secretkey/토큰/계좌번호는 `.env` 등 로컬 설정에만 저장하며 **절대 커밋하지 않습니다** (.gitignore로 차단).
- 백엔드는 인터넷에 직접 노출하지 않습니다 (포트포워딩 금지, VPN 경유만 허용).
- 실계좌 모드는 명시적 설정 전환으로만 활성화하고, 1회 주문 금액 상한 가드레일을 둡니다.

## 면책

이 프로젝트는 개인 투자 보조 도구입니다. 앱이 제시하는 추천·의견은 투자 조언이 아니며, 모든 투자 판단과 결과의 책임은 사용자 본인에게 있습니다.
